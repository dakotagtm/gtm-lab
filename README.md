# gtm-lab

Revenue systems for small businesses, built in public. Reusable toolkit only: CRM schemas, n8n flows, Claude Code skills, audit templates, playbooks. No client data.

## Index
- `audits/` the GTM audit: checklist, scorecard, report skill
- `crm/` schemas, pipelines, scoring, import scripts
- `flows/` n8n exports: inbound-to-crm, speed-to-lead, follow-ups, digest
- `skills/` Claude Code skills
- `agents/` qualifier, research agent, digest, eval sets
- `playbooks/` onboarding, access, handoff, SOPs
- `content/` post templates and explain-check scripts
